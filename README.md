BACKEND: hand-coded with Python 3 (app.py; quiz.txt; student_events.txt; ta_events.txt; instr_events.txt)
QUIZ.TXT: Random questions based on lecture PowerPoints & Exam 2 with four answer choices for each question.
STUDENT_EVENTS.TXT: Random happenings that alternate with each quiz question. Each question has two answer choices. Each answer choice has a 50/50 chance of returning a different outcome. Even if there is a "right answer," the consequences are arbitrary.
TA_EVENTS.TXT &  INSTR_EVENTS.TXT: Random happenings that do not alternate with quiz questions. Each question has two answer choices. Each answer choice has a 50/50 chance of returning a different outcome. Even if there is a "right answer," the consequences are arbitrary.
FRONTEND: Claude-coded with JavaScript and html (engine.js; index.html)
FRONTEND GRAPHICS: ChatGPT-generated with Google and Pinterest images (campus-photo.webp; instr-neutral.webp; instr-happy.webp; instr-worried.webp; student-neutral.webp; student-happy.webp; student-worried.webp; ta-neutral.webp; ta-happy.webp; ta-worried.webp)
DEPLOYMENT: static site via Render
